Projects

Scene Classification with Deep Learning | Python, PyTorch

Built a scene-classification system for a course Kaggle competition, classifying images into 17 scene categories. Designed an ensemble of four pretrained architectures (DINOv2-Large, Swin-Base, ConvNeXt-Base, EfficientNetV2-S) using custom model classes with manually loaded pretrained weights. Reduced overfitting with DropPath, EMA, CutMix/MixUp, layer-wise learning-rate decay, and staged unfreezing; combined models using test-time augmentation and weighted-average and geometric-mean ensembling.

Tiny Language Compiler | C#

Designed DFAs for lexical analysis and context-free grammar (CFG) rules for the Tiny language. Implemented the compiler's front end and back end in C#, including a recursive-descent parser and a two-pass semantic analyzer. Added semantic checks for duplicate declarations, undeclared identifiers, argument count and type mismatches, and return type mismatches.

Operating System Kernel: Memory Management and Process Scheduling (FOS) | C, x86

Enhanced a 32-bit kernel with a dynamic heap allocator using the Next-Fit algorithm, covering allocation, deallocation, and virtual-to-physical address translation. Implemented demand paging, page-fault handling, the Nth-Chance Clock page-replacement algorithm, and an MLFQ scheduler managing process priorities, ready queues, and CPU time quanta.

Single-Cycle 32-bit MIPS Processor | VHDL

Designed and implemented a 32-bit single-cycle MIPS processor in VHDL, integrating the datapath, control unit, memories, PC, multiplexers, adders, sign extender, and branch/jump logic. Built a 32-register file and custom ALU supporting arithmetic, logical, and comparison operations, verified via VHDL simulation.

FoodFlow: Online Food Ordering System | C#, SQL

Designed a full-stack database application modeled after modern food delivery platforms, with an ERD normalized to Third Normal Form (3NF). Wrote DDL and DML scripts, advanced SQL stored procedures for secure CRUD operations, and built Admin and Customer interfaces.
